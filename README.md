# Design Style Library

A browsable reference library of web design languages. Every card is one style:
a sample screenshot, a name, a short description, keywords, a category, and a
ready-to-paste **higgsfield.ai image prompt**.

**147 styles · 12 categories · 135 reference screenshots**

---

## Run it

```bash
npm start
```

Then open <http://localhost:4321>.

That's it — no dependencies, no build step, Node 18+ only.

> You can also just double-click `index.html` and it will work offline. The
> server is only needed for the auto-sync described below.

---

## Using it

| | |
|---|---|
| **Filter** | Category chips across the top. Counts update live. |
| **Search** | Matches titles, descriptions, keywords, traits and prompts. Press `/` to focus. |
| **Open a style** | Click any card. |
| **Copy brief** | A formatted text brief — summary, description, keywords, palette, typography/layout/colour/motion direction, and the image prompt. Good for handing to a designer or pasting into another AI. |
| **Copy image prompt** | Just the higgsfield.ai prompt. |
| **Copy a colour** | Click any swatch in the palette row. |
| **Theme** | `◐` in the header. Follows your OS by default. |
| **Close** | `Esc`, the `×`, the Close button, or click outside. |

## Adding to the library

### 1. Drop images in

Put new screenshots into `resources/` (`.jpg .jpeg .png .webp .gif .avif .svg`).

### 2. Refresh

If you're running `npm start`, **just reload the page.** The server re-scans
`resources/` on every request for the data file, so new images show up
immediately as **draft** cards, filed under the orange **Unsorted (new)**
category.

If you'd rather run it by hand:

```bash
npm run sync
```

It prints exactly what changed:

```
resources : 76 image(s)
styles    : 88 entr(ies), 2 draft(s)

new (added as drafts):
  + 8fa21c9e.jpg
  + c40d17bb.png
```

Deleting an image doesn't delete your writing — the entry stays and gets
flagged `image missing` so you can repoint or remove it deliberately.

### 3. Fill in the drafts

Open this folder in Claude Code and say:

> **classify the drafts in data/styles.json**

Claude reads the new screenshots, then writes the title, category, short and
long descriptions, keywords, palette, direction notes and the higgsfield prompt
for each one — matching the format of the existing entries. Reload the page and
the drafts become real cards.

You can of course also edit `data/styles.json` by hand; run `npm run sync`
afterwards to regenerate the file the browser reads.

## How the data works

```
resources/            your screenshots — the only thing you add by hand
data/styles.json      SOURCE OF TRUTH — categories + styles. Edit this.
data/styles.js        GENERATED by sync. Never edit; it's what the page loads.
scripts/sync.mjs      scans resources/, merges into styles.json, writes styles.js
scripts/serve.mjs     static server that runs sync on each data request
index.html            the page
assets/app.css        styling
assets/app.js         filtering, search, cards, modal, clipboard
```

`styles.js` (rather than fetching `styles.json`) is what lets `index.html` work
straight off the filesystem — `fetch()` of a local JSON file is blocked under
`file://`, a plain `<script>` isn't.

### A style entry

```jsonc
{
  "id": "neumorphism",                  // unique slug
  "title": "Neumorphism / Soft UI",
  "category": "tactile",                // must match a categories[].id
  "image": "resources/0568d2e4….jpg",   // or null for a style with no screenshot
  "previewLayout": "cards",             // only for image-less styles:
                                        // hero | grid | split | poster | cards
  "short": "One sentence for the card.",
  "long": "Two to four sentences for the modal.",
  "keywords": ["soft ui", "dual shadow", "…"],
  "palette": ["#e9edf0", "#ff7272", "…"],
  "traits": {
    "Typography": "…", "Layout": "…", "Colour": "…", "Motion": "…"
  },
  "prompt": "Full-page website UI screenshot in …, 1440px desktop viewport"
}
```

Styles with `"image": null` render a generated abstract preview built from their
palette — that's how the twelve styles with no screenshot yet (Glassmorphism,
Claymorphism, Vaporwave, Cyberpunk, Memphis, Bauhaus, Art Deco, Japandi, Dark
Academia, Scandinavian, Kinetic Type, Terminal) still appear in the grid. Give
one of them a real screenshot by dropping the file in `resources/` and setting
its `image` path.

### Adding a category

Append to `categories` in `data/styles.json`:

```jsonc
{ "id": "y2k", "name": "Y2K & Frutiger", "accent": "#8ad7ff", "blurb": "…" }
```

Empty categories are hidden from the filter bar automatically.

## Prompt conventions

Every `prompt` is written to describe **a screenshot of a website**, not an
abstract artwork, and ends with a viewport hint so the generator frames it as a
page. When you use one on higgsfield.ai:

- append your own subject or brand at the end,
- set a wide ratio (16:9) for desktop layouts or a tall one (2:3) for the
  poster-format styles,
- keep the closing viewport phrase — it's what stops the model producing a
  poster instead of a page.
